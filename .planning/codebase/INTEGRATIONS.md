# External Integrations

**Analysis Date:** 2026-05-03

## APIs & External Services

**HTTP/Web Integration:**
- Generic HTTP/HTTPS URL fetching via Roblox `HttpService`
  - Implementation: `src/server/init.server.luau` (lines 49-69)
  - Method: `HttpService:GetAsync(url)`
  - Validation: Only allows `http://` and `https://` URLs (line 53)
  - Client request flow: `RemoteFunction:InvokeServer(url)` → server fetches → returns HTML

**Default Bookmarks (pre-configured):**
- Wikipedia - `https://en.wikipedia.org/wiki/Main_Page`
  - Set as default homepage in `src/client/init.client.luau` (line 167)
- Google - `https://www.google.com`
  - Listed in bookmarks (line 31)

## Data Storage

**Databases:**
- None (no external database integration)
- Roblox DataStores not used in current implementation

**File Storage:**
- Roblox place file: `robrowser.rbxlx` (generated by Rojo)
- Local tool binaries in `tools/` directory:
  - `selene` (18MB binary)
  - `stylua` (12MB binary)

**Caching:**
- None (HTML is fetched fresh on each navigation)

## Authentication & Identity

**Auth Provider:**
- Roblox built-in authentication
  - Player identity via `Players.LocalPlayer` (client)
  - Server validates player in `RemoteFunction` callback (line 49 in server script)

**External Auth:**
- None (no external authentication required for HTML fetching)

## Communication Protocols

**Roblox Internal:**
- `RemoteFunction` - Client-server communication
  - Name: `FetchHTML`
  - Location: `ReplicatedStorage.FetchHTML`
  - Pattern: Client invokes server, server returns HTML string
  - Created in: `src/server/init.server.luau` (lines 41-47)

**External:**
- HTTP/HTTPS (via `HttpService`)
  - Method: GET (using `HttpService:GetAsync()`)
  - No custom headers or authentication tokens

## Web Services / Cloud Services

**None currently integrated.**

The project is a browser simulator that fetches arbitrary web pages, but does not integrate with:
- Cloud hosting providers
- SaaS APIs
- Payment processors
- Analytics services
- CDNs (uses direct URL fetching)

## Navigation & User Interaction

**Browser Navigation:**
- Back/Forward history management (client-side, `src/client/init.client.luau` lines 23-24)
- Bookmark storage (in-memory Lua table, lines 29-32)
- Address bar with manual URL entry
- Refresh functionality

**Event Handlers:**
- `MouseButton1Click` - Navigation buttons, link clicks
- `FocusLost` - Address bar (Enter key submission)
- `GetPropertyChangedSignal("AbsoluteSize")` - Responsive layout

## Monitoring & Observability

**Error Tracking:**
- None (no external error tracking service)

**Logging:**
- Custom debug module: `src/shared/debug.luau`
  - Levels: verbose, log, warn, error, none
  - Configurable via `src/shared/settings.luau` (default: "verbose")
  - Output: Roblox output console (`print`/`warn`)

## Limitations & Restrictions

**Roblox HttpService Constraints:**
- `HttpEnabled` must be enabled in game settings (`Game Settings > Security`)
- Cannot access local files or intranet URLs (Roblox sandbox)
- Rate limiting applied by Roblox (varies by game tier)
- No WebSocket support (HTTP only)
- No streaming responses (full page load only)

## Environment Configuration

**Required Settings:**
- Game Settings > Security > Enable HTTP Requests: **ON**
  - Checked at runtime in `src/server/init.server.luau` (lines 36-38)

**Secrets Location:**
- None required (no API keys or tokens needed for basic HTML fetching)

## Webhooks & Callbacks

**Incoming:**
- None (not a webhook receiver)

**Outgoing:**
- HTTP GET requests to user-specified URLs
- No webhook dispatch implemented
