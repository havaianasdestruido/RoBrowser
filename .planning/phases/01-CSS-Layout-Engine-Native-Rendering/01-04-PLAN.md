<task type="auto">
  <name>Task 1: Create BoxModelRenderer module (CSS-04)</name>
  <files>src/client/modules/BoxModelRenderer.luau</files>
  <action>
    Create `src/client/modules/BoxModelRenderer.luau` to handle CSS box model per CSS-04 requirement.
    
    Module structure:
    ```luau
    --!strict
    --!optimize 2
    --!native
    --[[
      BoxModelRenderer - Applies CSS box model to Roblox instances
      Maps width, height, padding, margin, overflow to Roblox properties
      Per UI-SPEC.md: rbx-css handles UIPadding for padding, UIStroke for border
      Per RESEARCH.md Pitfall 1: margin has no direct Roblox equivalent (use gap on parent)
    ]]
    
    local BoxModelRenderer = {}
    ```
    
    Implement `applyBoxModel(instance, cssProps)` function:
    
    1. Handle `width` and `height`:
       - Parse pixel values: `"200px"` → `UDim2.new(0, 200, instance.Size.Y.Scale, instance.Size.Y.Offset)`
       - Parse percentage: `"50%"` → `UDim2.new(0.5, 0, instance.Size.Y.Scale, instance.Size.Y.Offset)`
       - Set `instance.Size` accordingly
       - For `width: 100%` → `UDim2.new(1, 0, ...)`
       - For `height: auto` → keep existing height (don't modify)
    
    2. Handle `overflow` (per UI-SPEC.md mapping):
       - `"hidden"` → `instance.ClipsDescendants = true`
       - `"scroll"` or `"auto"` → Wrap instance in ScrollingFrame
         ```luau
         if cssProps["overflow"] == "scroll" or cssProps["overflow"] == "auto" then
             local scrollFrame = Instance.new("ScrollingFrame")
             scrollFrame.Size = instance.Size
             scrollFrame.Position = instance.Position
             scrollFrame.Parent = instance.Parent
             instance.Parent = scrollFrame
             instance.Position = UDim2.new(0, 0, 0, 0)
         end
         ```
       - `"visible"` (default) → `instance.ClipsDescendants = false`
    
    3. Handle `box-sizing` (per UI-SPEC.md):
       - `"border-box"` → Set `instance.SizeConstraint = Enum.SizeConstraint.RelativeXY` (default behavior)
       - Note: rbx-css handles box-sizing in compilation
    
    4. Handle `margin` (per RESEARCH.md Pitfall 1):
       - CSS margin has no direct Roblox equivalent
       - rbx-css emits warning for margin properties
       - For Phase 1, log warning and recommend using `gap` on parent flex/grid container
       - Alternative: Use UIPadding on parent container (not implemented in Phase 1)
    
    5. Handle `display: none`:
       - Set `instance.Visible = false`
    
    Implement `parsePixelValue(value: string): (number, boolean)`:
    - Returns (pixelValue, isPercentage)
    - "200px" → (200, false)
    - "50%" → (50, true)
    - "auto" → (0, false) with special handling
    
    Follow project conventions (stylua, selene, pcall for errors).
  </action>

    <automated>stylua --check src/client/modules/BoxModelRenderer.luau && selene src/client/modules/BoxModelRenderer.luau && test -f src/client/modules/BoxModelRenderer.luau</automated>
  </verify>
  <done>BoxModelRenderer.luau created with applyBoxModel() and parsePixelValue() functions. Handles width, height, overflow, box-sizing, margin warning. Passes stylua and selene.</done>
