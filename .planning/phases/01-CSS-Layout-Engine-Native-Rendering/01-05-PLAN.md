<task type="auto">
  <name>Task 1: Refactor BrowserEngine to use StyleSheets and native layouts</name>
  <files>src/client/modules/BrowserEngine.luau</files>
  <action>
    Refactor `src/client/modules/BrowserEngine.luau` to use rbx-css compiled StyleSheets and native layout engines (per D-01, D-02).
    
    Changes:
    
    1. Remove custom CSSParser require and usage:
       - Remove: `local CSSParser = loadModule("CSSParser")`
       - Remove: `cssMap = CSSParser.parse(domRoot.css)`
       - Remove: `CSSParser.matchElement(node, cssMap)` calls
    
    2. Add new module requires:
       ```luau
       local StyleSheetLoader = nil
       local LayoutEngine = nil
       local PositioningEngine = nil
       local BoxModelRenderer = nil
       
       pcall(function()
           local Shared = ReplicatedStorage:WaitForChild("Shared")
           local styles = Shared:WaitForChild("styles")
           StyleSheetLoader = require(styles:WaitForChild("StyleSheetLoader"))
           LayoutEngine = require(Shared:WaitForChild("modules"):WaitForChild("LayoutEngine"))
           PositioningEngine = require(Shared:WaitForChild("modules"):WaitForChild("PositioningEngine"))
           BoxModelRenderer = require(Shared:WaitForChild("modules"):WaitForChild("BoxModelRenderer"))
       end)
       ```
    
    3. In `render()` function, apply StyleSheet to ScreenGui:
       ```luau
       -- Apply StyleSheet to targetGui (ScreenGui)
       if StyleSheetLoader then
           StyleSheetLoader.init()
           StyleSheetLoader.applyStyleSheet(targetGui, StyleSheetLoader.compiledSheet)
       end
       ```
    
    4. Refactor `renderNode()` to use native layouts and positioning:
       - Remove old `applyStyles(instance, attrs, cssStyles)` call
       - Instead, tag instance with CSS class using `StyleSheetLoader.tagInstance(instance, className)`
       - Apply layout if element has display: flex/grid:
         ```luau
         if LayoutEngine and cssProps["display"] == "flex" then
             LayoutEngine.applyFlexboxLayout(inst, cssProps)
         elseif LayoutEngine and cssProps["display"] == "grid" then
             LayoutEngine.applyGridLayout(inst, cssProps)
         end
         ```
       - Apply positioning:
         ```luau
         if PositioningEngine and (cssProps["position"] or cssProps["z-index"]) then
             PositioningEngine.applyPositioning(inst, cssProps, targetGui)
         end
         ```
       - Apply box model:
         ```luau
         if BoxModelRenderer and (cssProps["width"] or cssProps["height"] or cssProps["overflow"]) then
             BoxModelRenderer.applyBoxModel(inst, cssProps)
         end
         ```
    
    5. Extract CSS properties from class names and inline styles:
       - Parse `class="flex justify-center p-4"` → extract class names
       - Parse `style="width: 200px; height: 100px;"` → extract inline styles
       - Combine into `cssProps` table to pass to engines
    
    6. Keep existing element creation logic (creatorForTag) - this stays the same.
    
    Follow project conventions. Run stylua and selene.
    Note: This is a significant refactor. Test thoroughly in Roblox Studio.
  </action>

  </verify>
  <done>BrowserEngine.luau refactored to use StyleSheetLoader, LayoutEngine, PositioningEngine, BoxModelRenderer. Custom CSSParser usage removed. Passes stylua and selene.</done>

    **Part 2: Deprecate CSSParser.luau**
    
    Update `src/shared/parsers/CSSParser.luau` with deprecation notice:
    ```luau
    --!strict
    --!optimize 2
    --!native
    --[[
      CSSParser - DEPRECATED
      This module has been replaced by rbx-css compiled StyleSheets.
      Per D-01: Use rbx-css to compile standard CSS to Roblox StyleSheet instances.
      This file is kept for reference only. Do not use in new code.
      Migration: Use StyleSheetLoader.lua + CompiledStyleSheet.luau instead.
    ]]
    
    local CSSParser = {}
    
    warn("CSSParser is deprecated. Use StyleSheetLoader with rbx-css compiled StyleSheets instead.")
    
    -- Keep function stubs for backwards compatibility (in case other code references them)
    function CSSParser.parse(cssText)
        warn("CSSParser.parse() is deprecated. Returning empty table.")
        return {}
    end
    
    function CSSParser.matchElement(element, styleMap)
        warn("CSSParser.matchElement() is deprecated. Returning empty table.")
        return {}
    end
    
    return CSSParser
    ```
    
    Run stylua and selene on both files.
