    Add section:
    ```markdown
    ## CSS Styling with rbx-css
    
    This project uses [rbx-css](https://github.com/AlroviOfficial/rbx-css) to compile standard CSS to Roblox `StyleSheet` instances.
    
    ### Workflow
    
    1. **Write CSS** in `src/styles/` directory:
       - `base.css` - Base element styles
       - `layout.css` - Flexbox and Grid layout classes  
       - `theme.css` - Design tokens (colors, spacing)
       - `demo.css` - Demo page styles
    
    2. **Compile CSS** to Roblox StyleSheet:
       ```bash
       npx rbx-css compile src/styles/*.css -o src/shared/styles/CompiledStyleSheet.luau
       ```
    
    3. **Sync to Roblox** using Rojo:
       ```bash
       rojo serve
       ```
       Then connect in Roblox Studio.
    
    ### CSS Features Supported (Phase 1)
    
    - **Flexbox**: `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`
    - **Grid**: `display: grid`, `grid-template-columns`, `grid-gap`
    - **Positioning**: `position: absolute/relative/fixed`, `top/left/right/bottom`, `z-index`
    - **Box Model**: `width`, `height`, `padding`, `overflow`, `box-sizing`, `display: none`
    
    ### CSS→Roblox Mapping
    
    | CSS Property | Roblox Implementation |
    |--------------|---------------------|
    | `display: flex` | `UIListLayout` (native C++ layout) |
    | `display: grid` | `UIGridLayout` (native C++ layout) |
    | `padding` | `UIPadding` pseudo-instance (auto-generated) |
    | `border-radius` | `UICorner` pseudo-instance (auto-generated) |
    | `border` | `UIStroke` pseudo-instance (auto-generated) |
    | `background-color` | `BackgroundColor3` |
    | `color` | `TextColor3` |
    ```
    
    Add Phase 1 completion status to README.
  </action>
  <verify>
    <automated>test -f README.md && grep -q "rbx-css" README.md && grep -q "Phase 1" README.md</automated>
  </verify>
  <done>README.md updated with rbx-css workflow documentation and CSS→Roblox mapping table.</done>
