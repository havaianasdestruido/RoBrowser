<task type="auto">
  <name>Task 1: Create LayoutEngine module with Flexbox support (CSS-01, REN-03)</name>
  <files>src/client/modules/LayoutEngine.luau</files>
  <action>
    Create `src/client/modules/LayoutEngine.luau` per D-02 (use native UIListLayout for Flexbox, UIGridLayout for Grid).
    
    Module structure:
    ```luau
    --!strict
    --!optimize 2
    --!native
    --[[
      LayoutEngine - Applies CSS Flexbox and Grid layouts using native Roblox layouts
      Per D-02: Uses UIListLayout (Flexbox) and UIGridLayout (Grid)
      Replaces per-frame Luau positioning with native C++ layouts
    ]]
    
    local LayoutEngine = {}
    
    local Enum = Enum
    ```
    
    Implement `applyFlexboxLayout(container, cssProps)` function:
    - Creates UIListLayout parented to container
    - Maps CSS `flex-direction` to `UIListLayout.FillDirection`:
      - `row` → `Enum.FillDirection.Horizontal`
      - `column` → `Enum.FillDirection.Vertical`
    - Maps CSS `justify-content` to `UIListLayout.HorizontalFlex`/`VerticalFlex`:
      - `flex-start` → `Enum.UIFlexAlignment.Start`
      - `center` → `Enum.UIFlexAlignment.Center`
      - `flex-end` → `Enum.UIFlexAlignment.End`
      - `space-between` → `Enum.UIFlexAlignment.SpaceBetween`
      - `space-around` → `Enum.UIFlexAlignment.SpaceAround`
    - Maps CSS `align-items` to `UIListLayout.VerticalAlignment`/`HorizontalAlignment`:
      - `stretch` → `Enum.VerticalAlignment.Center` (native behavior)
      - `flex-start` → `Enum.VerticalAlignment.Top`
      - `center` → `Enum.VerticalAlignment.Center`
      - `flex-end` → `Enum.VerticalAlignment.Bottom`
    - Maps CSS `flex-wrap: wrap` to `UIListLayout.Wraps = true`
    - Sets `UIListLayout.Padding` based on CSS `gap` property (convert px to UDim)
    
    Implement `applyGridLayout(container, cssProps)` function:
    - Creates UIGridLayout parented to container
    - Maps CSS `grid-template-columns` to `UIGridLayout.CellSize`:
      - Parse `repeat(N, 1fr)` or fixed values like `100px 100px`
      - For simplicity, use fixed CellSize for Phase 1 (e.g., UDim2.new(0, 100, 0, 100))
    - Maps CSS `grid-gap` to `UIGridLayout.CellPadding`
    - Sets `UIGridLayout.FillDirection = Enum.FillDirection.Horizontal`
    
    Implement `applyLayout(element, cssProps)` dispatcher:
    - Checks `cssProps["display"]`:
      - `"flex"` → calls `applyFlexboxLayout(element, cssProps)`
      - `"grid"` → calls `applyGridLayout(element, cssProps)`
      - Otherwise → no layout applied (static positioning)
    
    Follow project conventions:
    - Use pcall for error handling
    - Use camelCase for functions, PascalCase for module table
    - Run `stylua src/client/modules/LayoutEngine.luau`
    - Run `selene src/client/modules/LayoutEngine.luau`
  </action>
  <verify>
    <automated>stylua --check src/client/modules/LayoutEngine.luau && selene src/client/modules/LayoutEngine.luau && test -f src/client/modules/LayoutEngine.luau</automated>
  </verify>
