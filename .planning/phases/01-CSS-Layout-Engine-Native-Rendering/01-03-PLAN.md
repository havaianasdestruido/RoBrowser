  <name>Task 1: Create PositioningEngine module (CSS-03)</name>
  <files>src/client/modules/PositioningEngine.luau</files>
  <action>
    Create `src/client/modules/PositioningEngine.luau` to handle CSS positioning per CSS-03 requirement.
    
    Module structure:
    ```luau
    --!strict
    --!optimize 2
    --!native
    --[[
      PositioningEngine - Applies CSS positioning to Roblox instances
      Maps CSS position property to Roblox Position, AnchorPoint, ZIndex
      Per UI-SPEC.md: position:fixed requires special handling (parent to ScreenGui)
    ]]
    
    local PositioningEngine = {}
    
    local Players = game:GetService("Players")
    ```
    
    Implement `applyPositioning(instance, cssProps, parentGui)` function:
    
    1. Handle `position` property:
       - `"absolute"`: Standard Roblox positioning (default). Use cssProps top/left/right/bottom to set Position.
       - `"relative"`: Same as absolute in Roblox (Position is always relative to parent). No special handling needed.
       - `"fixed"`: Parent instance directly to ScreenGui (not ScrollingFrame). 
         - Get ScreenGui: `Players.LocalPlayer:WaitForChild("PlayerGui"):FindFirstChild("BrowserScreen")`
         - Reparent if needed (only for fixed elements)
    
    2. Handle offset properties (top, left, right, bottom):
       - Parse pixel values from cssProps (e.g., "10px" → 10)
       - For `position: absolute`:
         - `left` → `instance.Position = UDim2.new(0, leftVal, instance.Position.Y.Scale, instance.Position.Y.Offset)`
         - `top` → `instance.Position = UDim2.new(instance.Position.X.Scale, instance.Position.X.Offset, 0, topVal)`
         - `right` → Adjust X offset from right (requires parent width knowledge - use AnchorPoint)
         - `bottom` → Adjust Y offset from bottom (requires parent height - use AnchorPoint)
    
    3. Handle `z-index`:
       - Parse numeric value from cssProps["z-index"]
       - Set `instance.ZIndex = tonumber(zIndexVal) or 1`
    
    4. Special handling for `position: fixed` (per RESEARCH.md Pitfall 6):
       ```luau
       if cssProps["position"] == "fixed" then
           -- Parent to ScreenGui instead of ScrollingFrame
           local screenGui = Players.LocalPlayer:FindFirstChild("PlayerGui"):FindFirstChild("BrowserScreen")
           if screenGui and instance.Parent ~= screenGui then
               instance.Parent = screenGui
           end
           -- Use AbsolutePosition for fixed positioning
           -- Set AnchorPoint for proper centering if needed
       end
       ```
    
    Implement `parsePixelValue(value: string): number`:
    - Convert "10px" to 10, "1rem" to 16 (approximate), "%50" to 0.5
    - Return 0 if parsing fails
    
    Follow project conventions (stylua, selene, pcall for errors).
  </action>

  </verify>
  <done>PositioningEngine.luau created with applyPositioning() and parsePixelValue() functions. Handles absolute/relative/fixed positioning and z-index. Passes stylua and selene.</done>
