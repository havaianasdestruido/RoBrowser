# Phase 01 — UI Design Contract

> Visual and interaction contract for CSS Layout Engine & Native Rendering phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Project Context:** Roblox Luau project (not web). Uses native Roblox GUI objects, not HTML/CSS/JS.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Roblox native GUI) |
| Preset | not applicable |
| Component library | Roblox native: Frame, TextLabel, TextButton, ImageLabel, ScrollingFrame |
| Layout engine | UIListLayout (Flexbox), UIGridLayout (Grid) — native C++ layouts |
| StyleSheet compiler | rbx-css (CSS → Roblox StyleSheet) |
| Icon library | Roblox built-in (not needed for Phase 1) |
| Font | SourceSans (Roblox default, Enum.Font.SourceSans) |

## Spacing Scale

Declared values (Roblox offset pixels, equivalent to CSS px):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding in rendered content |
| sm | 8px | Compact element spacing in browser chrome |
| md | 16px | Default element spacing, UIPadding on Frames |
| lg | 24px | Section padding in browser chrome |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 
- Roblox `UIListLayout.Padding` uses UDim format (0, 4) for 4px, not CSS-style margins
- `UIPadding.PaddingLeft/PaddingRight/PaddingTop/PaddingBottom` uses UDim2
- CSS `margin`/`padding` from websites map to Roblox `UIPadding` via rbx-css compilation

## Typography

Roblox font sizing (TextSize property, equivalent to CSS px):

| Role | Size | Weight | Line Height | Roblox Font |
|------|------|--------|-------------|-------------|
| Body (rendered text) | 14px | 400 (normal) | 1.5 | Enum.Font.SourceSans |
| Label (browser chrome) | 14px | 400 (normal) | 1.5 | Enum.Font.SourceSans |
| Heading (h1-h6 rendered) | 20px (h3), 24px (h2), 32px (h1) | 700 (bold) | 1.2 | Enum.Font.SourceSansBold |
| Display (not used in Phase 1) | N/A | N/A | N/A | N/A |

**Roblox Font Mapping (from rbx-css convention):**
- CSS `font-weight: normal` → `Enum.Font.SourceSans`
- CSS `font-weight: bold` → `Enum.Font.SourceSansBold`
- CSS `font-style: italic` → `Enum.Font.SourceSansItalic`
- CSS `font-weight: bold; font-style: italic` → `Enum.Font.SourceSansBoldItalic`

## Color

**Browser Chrome Colors** (the robrowser UI itself):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Color3.fromRGB(240, 240, 240) | Browser background, chrome surfaces |
| Secondary (30%) | Color3.fromRGB(255, 255, 255) | Content area, rendered page background |
| Accent (10%) | Color3.fromRGB(0, 102, 204) | Links in rendered content, active states |
| Destructive | Color3.fromRGB(204, 0, 0) | Error states, destructive actions (future phases) |

**Rendered Website Colors** (controlled by CSS → rbx-css → StyleSheet):
- CSS `color` → Roblox `TextLabel.TextColor3`
- CSS `background-color` → Roblox `Frame.BackgroundColor3`
- CSS `border-color` → Roblox `UIStroke.Color`
- rbx-css handles all color conversions from CSS hex/rgb to Roblox Color3

Accent reserved for: Links (`:link` pseudo-class), active navigation states, focus indicators.

## CSS→Roblox Mapping Contract

**This is the core visual contract for Phase 1.** rbx-css compiles standard CSS to Roblox StyleSheets.

### Element Mapping (HTML → Roblox)

| HTML Element | Roblox Instance | rbx-css Handling |
|--------------|-----------------|-------------------|
| `div`, `section`, `article`, `header`, `footer`, `nav` | `Frame` | Auto-mapped by rbx-css element selector |
| `p`, `h1`-`h6`, `span`, `a`, `strong`, `em` | `TextLabel` | Auto-mapped by rbx-css element selector |
| `button`, `input[type=button]` | `TextButton` | Auto-mapped by rbx-css element selector |
| `img` | `ImageLabel` | Auto-mapped by rbx-css element selector |

### CSS Flexbox → UIListLayout

| CSS Property | Roblox Property | rbx-css Compiles To |
|--------------|-----------------|---------------------|
| `display: flex` | `Frame` + `UIListLayout` | `Instance.new("UIListLayout")` parented to Frame |
| `flex-direction: row` | `UIListLayout.FillDirection = Horizontal` | `.FillDirection = Enum.FillDirection.Horizontal` |
| `flex-direction: column` | `UIListLayout.FillDirection = Vertical` | `.FillDirection = Enum.FillDirection.Vertical` |
| `justify-content: flex-start` | `UIListLayout.HorizontalAlignment = Left` | `.HorizontalAlignment = Enum.HorizontalAlignment.Left` |
| `justify-content: center` | `UIListLayout.HorizontalAlignment = Center` | `.HorizontalAlignment = Enum.HorizontalAlignment.Center` |
| `justify-content: flex-end` | `UIListLayout.HorizontalAlignment = Right` | `.HorizontalAlignment = Enum.HorizontalAlignment.Right` |
| `align-items: stretch` | `UIListLayout.VerticalAlignment = Center` + `FlexMode` | Native layout behavior |
| `align-items: flex-start` | `UIListLayout.VerticalAlignment = Top` | `.VerticalAlignment = Enum.VerticalAlignment.Top` |
| `align-items: center` | `UIListLayout.VerticalAlignment = Center` | `.VerticalAlignment = Enum.VerticalAlignment.Center` |
| `flex-wrap: wrap` | `UIListLayout.Wraps = true` | `.Wraps = true` |
| `gap: Npx` | `UIListLayout.Padding` + `HorizontalFlex`/`VerticalFlex` | Compiled to UDim padding |

### CSS Grid → UIGridLayout

| CSS Property | Roblox Property | rbx-css Compiles To |
|--------------|-----------------|---------------------|
| `display: grid` | `Frame` + `UIGridLayout` | `Instance.new("UIGridLayout")` parented to Frame |
| `grid-template-columns: repeat(N, 1fr)` | `UIGridLayout.CellSize` + `CellPadding` | Calculated from fr units |
| `grid-gap: Npx` | `UIGridLayout.CellPadding` | `.CellPadding = UDim2.new(0, N, 0, N)` |

### CSS Box Model → Roblox Properties

| CSS Property | Roblox Property | rbx-css Compiles To |
|--------------|-----------------|---------------------|
| `margin: Npx` | `UIPadding` on parent or negative offset | Handled via StyleSheet `margin` property |
| `padding: Npx` | `UIPadding` on element | `Instance.new("UIPadding")` with UDim2 values |
| `width: Npx` | `Size = UDim2.new(0, N, 0, H)` | Direct property mapping |
| `height: Npx` | `Size = UDim2.new(0, W, 0, N)` | Direct property mapping |
| `overflow: hidden` | `ClipsDescendants = true` | `.ClipsDescendants = true` on Frame |
| `overflow: scroll` | `ScrollingFrame` wrapper | Element wrapped in `ScrollingFrame` |
| `box-sizing: border-box` | `SizeConstraint = RelativeXY` | Handled in rbx-css compilation |

### CSS Positioning → Roblox Properties

| CSS Property | Roblox Property | rbx-css Compiles To |
|--------------|-----------------|---------------------|
| `position: relative` | Default Frame behavior | No special handling needed |
| `position: absolute` | `Position = UDim2.new(0, left, 0, top)` | Absolute positioning within parent |
| `position: fixed` | `Position` relative to ScreenGui | Requires special handling (not in native rbx-css) |
| `top/left/right/bottom: Npx` | `Position` or `AnchorPoint` | Mapped to UDim2 offset values |
| `z-index: N` | `ZIndex = N` | `.ZIndex = N` on GuiObject |

## Browser Chrome Minimal Spec

**Scope:** Phase 1 renders websites. Minimal browser chrome needed:

1. **ScreenGui** — Root container in PlayerGui
   - BackgroundColor3: Color3.fromRGB(240, 240, 240)
   - Size: UDim2.new(1, 0, 1, 0) (full screen)

2. **Content Frame** — Wraps rendered website
   - BackgroundColor3: Color3.fromRGB(255, 255, 255)
   - Size: Fills ScreenGui (minus any navigation chrome)
   - ClipsDescendants: true (for overflow: hidden)

3. **Navigation UI** (existing, not modified in Phase 1):
   - Back/Forward/Refresh buttons (TextButton)
   - URL input (TextBox)
   - These exist in `src/client/init.client.luau`, not modified this phase
